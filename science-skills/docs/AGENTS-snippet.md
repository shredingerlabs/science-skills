## Scientific workflow

This repo uses the science skills (`science-flow` routes to the right one). Five laws apply even when no skill triggers:

1. **No data before a question.** Do not load, plot or model outcome data until a falsifiable question is agreed.
2. **No confirmatory claim without a frozen prediction.** Anything analysed before the plan is frozen is exploratory, and is labelled so.
3. **No claim without a verified source or a reproduced result.** Open the source and find the claim; rerun the code and compare. Never cite from memory.
4. **No inconvenient data dropped silently.** Diagnose anomalies; log every analysis run and every deviation in `docs/science/LOG.md`.
5. **No self-grading.** Results are reviewed by a fresh, read-only reviewer who sees artifacts, not your reasoning.

Raw data is read-only. Every number in a report comes from a script's output file.
